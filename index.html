The agent comes first.

tmux and zellij don't know anything about agents. trix is built around what each agent is doing.

⚓

Agents report in

Agents tell trix when you send a prompt, when they run a tool, when they need you and when they finish. trix doesn't scrape the screen to guess, and it never edits your agent configs.

▲

Never miss one that needs you

When an agent is waiting on you, a red bar drops over the pane you're in, and you get a desktop notification and a bell. A chime plays when work you haven't seen finishes.

⌥

One key to what matters

Press alt+a to jump to the agent that has waited on you the longest. If nothing is waiting, it takes you to finished work you haven't looked at yet.

▦

See every agent at once

Press alt+g to see your agents side by side, updating live. Agents waiting on you turn red, so you know where to look first.

⑂

Worktrees built in

Each agent can work in its own git worktree on its own branch, so agents running in parallel never overwrite each other's files.

↻

Close the window, keep the agents

Agents run in a background server. Close the terminal and they keep working. After a crash or a reboot, each one resumes the conversation it was in.

Also: search across every agent, one prompt to many agents, a context gauge, layouts, named sessions and 24 themes. Full feature list ↗

Bring your agent.

trix starts each agent itself and hands it what it needs, so your configs stay untouched. If you don't have an agent yet, its pane installs it the first time you start it.

Agents can run agents.

A script, or an agent in another pane, can start agents, send them prompts, wait for them and read what they did. trix never answers a permission prompt for you.

$ trix spawn claude --name api --worktree \
--prompt "add rate limiting to /login"
api ~/code/web/.trix/worktrees/api
$ trix send api "also cover it with a test"
sent to api
$ trix wait api # blocks until api stops working
api done turn finished
$ trix read api -n 80 # its last 80 lines
$ trix ls --json # state, activity, branch, diff…

Questions.

Short answers. The README has the long ones.

What is trix?

trix is a free, open-source terminal workspace for AI coding agents. It runs Claude Code, Codex, Gemini CLI, Cursor, GitHub Copilot CLI, OpenCode and any other CLI agent side by side, and shows at a glance which one is working, which one needs you and which one has finished. It's written in Rust, MIT licensed, and runs on Linux and macOS.

How do I run several Claude Code sessions at once?

Run trix claude in your project, then press alt+n to start each new agent. Choose "Worktree" in the new-agent dialog to give an agent its own git worktree and branch, so agents working in parallel never overwrite each other's files. Press alt+g to see up to four of them side by side.

How do I know when Claude Code or Codex is waiting for my input?

Agents report their state to trix through hooks, so trix knows the moment one asks for permission or asks you a question. A red strip covers the title of the pane you're in, and you get a desktop notification and a terminal bell. Press alt+a to jump to the agent that has waited longest.

How is trix different from tmux?

tmux and zellij are general terminal multiplexers that know nothing about agents. trix starts each agent itself and gets live state from it: what it's doing, when it needs you, when it's done, and for Claude and Codex, how full its context window is and what it has cost. It also creates a git worktree for each parallel agent, lets you review and merge an agent's diff, and brings each agent back into its conversation after a reboot. Like tmux, it keeps agents running when you close the terminal.

Does trix change my agent configs?

No. Everything trix hands an agent, such as Claude Code's hooks, is passed to that one process and kept only until trix's server stops. trix also never answers a permission prompt for you.

Is trix free, and what does it run on?

Yes, trix is free and open source under the MIT license. It runs on Linux and macOS, on x86_64 and ARM. There is no Windows build. Install it with brew install leofle/trix/trix, or with the pacman package on Arch Linux and Omarchy.
